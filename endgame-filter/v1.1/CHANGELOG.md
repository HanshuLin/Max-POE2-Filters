# POE2 Endgame Value Filter V1.1 — 交接说明

## 1. 交付文件

| 文件 | 用途 |
| --- | --- |
| `poe2_endgame_value_filter_v1_1.filter` | 可直接用于 POE2 的终局速刷物品过滤器 |
| `poe2_endgame_value_filter_v1_1_review.html` | 单文件、离线可打开的规则与市场定级 Review 页面 |
| `POE2_Endgame_Value_Filter_V1.1_交接说明.md` | 本交接文档，供后续新对话或下一版本继续开发 |

V1.1 是独立版本，保留 V1，不覆盖旧文件。它也不同于较早的 `POE2_降临_异界速刷_赛季末_V7.filter` 系列；旧系列仅作为视觉与分类方案参考。

## 2. 使用场景与数据快照

- 游戏版本：POE2 0.5。
- 场景：软核交易服赛季末、终局 T15 异界速刷。
- 目标：大幅减少低价值掉落与视觉噪声，优先保证单位时间收益。
- 经济快照：`2026-08-03 18:00:00 Asia/Shanghai`。
- 换算快照：`1C = 213E`，`1D = 970E`。
- 价格带：绿色 `>=1C`；蓝色 `>=1D`；紫色 `>=3D`；红色 `>=100D`。
- 传奇装备代理数据：NeverSink `0.10.3`；`<=T3` 隐藏，`T2` 蓝色，`T1` 紫色，传奇装备最高封顶紫色。

这些价格是生成时的静态快照，不会自动随市场更新。下次更新市场数据时，应重新生成 Filter 与 HTML，而不是只改 HTML 展示。

## 3. 最终品级语义

颜色表示“注意力与拾取优先级”，不是物品原生稀有度。V1.1 的经济物品不使用灰色展示层：已知低价物品直接隐藏，未知的新经济物品使用白色安全回退。

| 品级 | 价值阈值 | 标签颜色 | 光柱 | 声音 | 默认动作 |
| --- | ---: | --- | --- | --- | --- |
| R5 红 | `>=100D` | `#FF2020` | 红色永久 | 高优先级 | 立即中断路线拾取 |
| P4 紫 | `>=3D` | `#A335EE` | 紫色永久 | 高优先级 | 必捡 |
| B3 蓝 | `>=1D` | `#0070DD` | 蓝色永久（当前生成文件） | 高优先级 | 默认拾取 |
| G2 绿 | `>=1C` | `#1EFF00` | 绿色临时 | 中等提示 | 通常拾取 |
| W1 白 | 安全回退/强制保留 | `#FFFFFF` | 无 | 无 | 顺路拾取或快速判断 |
| H 隐藏 | `<1C`、明确无价或不符合终局条件 | 不显示 | 无 | 无 | 忽略 |

全局普通标签字号为 `32`，黑色半透明背景为 `0 0 0 220`。金币是例外，字号为 `24`。

## 4. 功能类别与视觉语义

| 类别 | 标签/边框 | 小地图图标 |
| --- | --- | --- |
| 装备 | 依据品级；高价值装备使用同品级边框 | Hexagon；追逐级珠宝底材使用 Star |
| 镶嵌物 | 更明显的紫色边框 `132 62 170 255` | Diamond |
| 门票 | 柔化白色边框 `220 220 220 180` | Square |
| 使用消耗品 | 柔化白色边框 `220 220 220 180` | Raindrop |
| 制作品 | 默认无边框；保持通货类视觉 | 高价值时使用 Star 或 Triangle，按成品规则执行 |

后续讨论形成的覆盖规则：技能宝石属于“制作品”，不要归入“镶嵌物”。符文和灵魂核心仍属于镶嵌物。

## 5. V1.1 相比 V1 的最终修正

1. 维金（`Verisium`、`Exceptional Verisium`、`Liquid Verisium`）不再按经济品级着色，统一使用任务物品式棕色标签、棕色边框和小棕星。
2. 维金堆叠量 `>500` 时增加永久棕色光柱；`<=500` 不显示光柱；两者均无提示音。
3. 精华、催化剂、液化情感、符文、灵魂核心、合金与溶液严格遵循市场价格评级。
4. 上述经济物品 `<1C` 或明确无价时隐藏，不再因为类别本身获得最低显示品级。
5. 尚未被价格快照识别的新经济物品保留白色安全回退，避免新赛季物品被终端规则误删。

## 6. 特殊规则

### 任务与区域物品

- `Quest Items` 与 `Instance Local Items` 具有绝对最高规则优先级。
- 使用棕色文字、棕色边框、小棕星，无提示音。

### 金币

- `BaseType == "Gold"`。
- 使用游戏默认文字外观，字号 `24`。
- 无边框、无图标、无光柱、无提示音。

### 石板

- 传奇石板：R5 红色、红星、永久红色光柱与高优先级提示音。
- 仪式石板（`Ritual Tablet`）：P4 紫色、紫色方形图标、永久紫色光柱与提示音。
- 深渊、裂隙、迷雾、辐射、霸主、神庙石板：B3 蓝色、蓝色方形图标与光柱。
- 未识别的新石板：W1 白色安全回退，柔化白色边框。

### 宝石

- 指定命名宝石谱系显示为 W1。
- `GemLevel 20` 的技能宝石、未切割技能宝石和未切割精魂宝石显示为 W1。
- 普通辅助宝石、普通技能宝石和非 20 级未切割宝石隐藏。

### 引路石与碎片

- 仅显示 T15 引路石，使用 W1 标签和柔化白色门票边框；其余引路石隐藏。
- 裂隙、请愿、符文、幻像碎片设有 W1 最低保留规则，但更高市场定级规则优先。

### 卓越装备代理规则

Filter 语法无法直接匹配“卓越”前缀，因此使用可执行条件代理：

- 所有装备 `Quality >= 21`：G2。
- 双手/大型装备 `Sockets >= 3`：G2。
- 其余可打孔装备 `Sockets >= 2`：G2。

### 装备总体策略

- 普通装备默认隐藏，不因高物品等级或高底材等级自动显示。
- 高价值珠宝底材、传奇共享底材和卓越代理规则必须位于最终装备隐藏规则之前。
- 已知低价值传奇底材先隐藏；未识别的新传奇底材使用白色边框安全回退。

## 7. 规则优先级

Filter 采用自上而下首次匹配逻辑，顺序不可随意调整：

1. 任务与区域物品。
2. 金币。
3. 维金堆叠与普通维金。
4. 传奇石板、仪式石板、其他固定石板。
5. 已有市场价格的非装备经济物品，按红→紫→蓝→绿排列。
6. 高价值传奇/共享底材。
7. 高价值珠宝底材。
8. 卓越装备代理规则。
9. 宝石。
10. T15 引路石。
11. 基础进度碎片。
12. 已知低价或无价经济物品隐藏。
13. 已知低价传奇底材隐藏与未知传奇回退。
14. 未知新经济物品白色安全网。
15. 所有剩余装备隐藏与终端隐藏。

## 8. HTML Review 页面

HTML 是完全自包含的单文件，可直接用浏览器离线打开，不依赖外部服务器。主要列为：

- 品级视觉
- Filter 图标
- 类别标签
- 中文名
- `BaseType`
- 原始报价
- 折合 C
- 折合 D
- 状态

表头支持排序，并提供搜索与筛选。页面数据与 V1.1 Filter 使用同一份生成快照。
