# POE2 Endgame Value Filter V1.31 — Change Log

发布日期：2026-08-06  
基线版本：V1.3  
适用场景：POE2 0.5，软核交易服赛季末，终局 T15 异界速刷

## 本次变更

### 特殊门票与终局钥匙改为 B3 蓝色保底

以下两个已知物品不再按低价值规则隐藏，统一以 B3 蓝色显示：

- `An Audience with the King`（谒王之约）
- `Call of the Shadows`（暗影呼唤）

两者使用门票视觉语义：

- 蓝色文字：`51 153 238 255`
- 字号：`36`
- 柔化白色门票边框：`220 220 220 255`
- 蓝色永久光柱
- 中号蓝色 Square 小地图图标
- 自定义音效：`blue.mp3`

这是一条类别保底规则，不受旧经济快照中低于 `1C` 的定价影响。规则位于已知低价值隐藏名单之前，并已从隐藏名单中移除这两个 BaseType。

## 市场复核

- 谒王之约在 V1.3 快照中为 `0.14C / 0.03D`。
- 暗影呼唤在 V1.3 快照中为 `0.77C / 0.17D`。
- 2026-08-06 复核时两者仍低于 `1C`，但因属于特殊门票/终局钥匙，V1.31 固定提升到 B3。

## 未变更内容

- 其余物品的经济快照、换算关系和市场评级保持 V1.3 不变。
- 装备、通货、普通碎片和未知经济物品规则保持 V1.3 不变。
- 高价值门票原有的紫色或红色规则不受影响。

## 验证结果

- 两个 BaseType 均在低价值隐藏规则之前命中 B3 `Show`。
- 两个 BaseType 均已从已知低价值 `Hide` 名单移除。
- Filter 与 HTML Review 的评级和视觉状态保持一致。
